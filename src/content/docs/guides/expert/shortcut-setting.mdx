这里罗列了挖坟常用的快捷键，并提供了推荐键位。熟练使用快捷键是高效挖坟的保证，也是小白挖穿超冬三层的必要前提。大部分快捷键是按住以后再用鼠标选择目标才能发挥作用。

| 名称                          | 功能                                    | 推荐键位                         |
| ----------------------------- | --------------------------------------- | -------------------------------- |
| **战斗**                      |                                         |                                  |
| <EveLocText locId={237262} /> | 靠近                                    | 无                               |
| <EveLocText locId={510254} /> | 舰载扫描                                | <kbd>X</kbd>                     |
| <EveLocText locId={237217} /> | 停泊/跃迁/激活星门                      | <kbd>Alt</kbd>                   |
| <EveLocText locId={232310} /> | 保持距离                                | <kbd>C</kbd>                     |
| <EveLocText locId={237116} /> | 锁定目标，用鼠标可框选                  | <kbd>Ctrl</kbd>                  |
| <EveLocText locId={237183} /> | 解锁目标，用鼠标可框选                  | <kbd>Shift</kbd>                 |
| <EveLocText locId={237175} /> | 环绕                                    | <kbd>V</kbd>                     |
| <EveLocText locId={510255} /> | 使用探针扫描，没探针会自动放            | <kbd>Z</kbd>                     |
| <EveLocText locId={287833} /> | 标记目标从数字 1-9 顺序标记，需要开舰队 | <kbd>1</kbd>                     |
| <EveLocText locId={287137} /> | 标记目标为 A，排除不值钱箱子            | <kbd>2</kbd>                     |
| **导航**                      |                                         |                                  |
| <EveLocText locId={61359} />  | 保存位置                                | <kbd>Ctrl</kbd>-<kbd>B</kbd>     |
| <EveLocText locId={237227} /> | 停船                                    | <kbd>Ctrl</kbd>-<kbd>Space</kbd> |
| **装备**                      |                                         |                                  |
| <EveLocText locId={237240} /> | 启用高槽 1，隐身                         | <kbd>Q</kbd>                     |
| <EveLocText locId={237118} /> | 启用中槽 1，推子                         | <kbd>Space</kbd>                 |
| <EveLocText locId={237141} /> | 启用中槽 2，货柜扫描                     | <kbd>A</kbd>                     |
| <EveLocText locId={237144} /> | 启用中槽 3，数据/一体分析仪              | <kbd>S</kbd>                     |
| <EveLocText locId={237225} /> | 启用中槽 4，遗迹分析仪                   | <kbd>D</kbd>                     |
